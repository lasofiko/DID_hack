# Архитектура

- **apps/frontend** — интерфейс оператора: управление миссией, карта, телеметрия.
- **apps/backend** — API для фронта и связь с исполнителем миссии.
- **packages/contracts** — общие форматы наблюдений, подцелей и событий.
- **packages/agent** — состояния миссии, проверка подцелей и планирование пути.
- **packages/ml** — LLM-клиент, промпты, модель расхода и адаптация.
- **packages/environment** — скрытые сценарии, датчик и судья.
- **ros2** — ROS-узлы, контроллер движения, интеграция Gazebo.

Будущий поток: фронт → бэкенд → агент → ROS. Наблюдения идут обратно.
LLM предлагает подцели; агент их проверяет, ROS управляет скоростью.
Агент не получает скрытые координаты образцов из environment.

Сейчас реализована только проверка связи frontend → GET /api/health.
В contracts добавлены только типы и подписи интерфейсов. Остальные модули —
пустые Python-пакеты или папки с TODO.

Рабочие договорённости: [задачи команды](team.md), [HTTP/WS](api.md).

ML больше не пустой: офлайн-планировщик реализован в packages/ml/did_ml.
Общие контракты, backend, frontend и ROS в этой доработке не изменены.
Инструкция интеграции: [ML](../packages/ml/README.md).
