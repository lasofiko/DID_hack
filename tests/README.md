# Tests

Проверки ML без LLM и ROS: `python scripts/test_ml.py` из корня.
Тесты используют искусственные публичные наблюдения и подставной провайдер.
Они не являются экспериментами в Gazebo или оценкой качества реальной LLM.

HTTP-адаптер МАИ проверяется через httpx.MockTransport (без сети).
Перед всем набором тестов: `python -m pip install -e ".[ml]"`.
Живая проверка API — отдельная явная команда `python scripts/check_llm.py`.
