# DID LAB — консоль автономного исследователя

React/TypeScript frontend существующего FastAPI/ROS-проекта. Рабочий экран:
локализованная шапка → показатели → большая карта + решение агента и команды →
энергетическая модель и журнал. Русский и татарский переключаются без reload.
В презентации карта и показатели увеличиваются, настройки и энергетический
инспектор скрываются; Pause/Resume/Return/Stop остаются доступны. Выход — кнопка
в шапке или Escape.

## Локальный запуск

Нужен Node.js 22.18+ (проверки здесь выполнены на Node 24.19.0).
Из корня checkout:

```sh
cd apps/frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Vite проксирует `/api` и WebSocket на
http://127.0.0.1:8000. Для настоящей телеметрии нужен существующий backend,
запускаемый по [QUICK_START](../../docs/QUICK_START.md).
Без него показывается честное состояние потери связи; миссия не стартует сама.
В Docker готовый `dist` обслуживает FastAPI с того же origin.

```sh
npm test
npm run build
```

Ранее отдельных frontend-тестов не было. Добавлены Node unit-тесты и проверки
типобезопасности переводов; runtime-библиотеки и версии зависимостей сохранены.

## Браузерная проверка без ROS

**Только тестовый стенд с синтетическими данными — не реальная миссия.**
При выключенном настоящем backend в отдельном терминале:

```sh
cd apps/frontend
npm run test:fixture
```

Этот сервер на 127.0.0.1:8000 реализует публичные API-форматы, записывает запросы
в `/__test/requests` и отдаёт тестовую карту/телеметрию. Он не импортируется
приложением и не входит в production bundle. После теста остановить Ctrl+C.
Не запускать одновременно с настоящим backend.

Структура: `src/main.tsx` — транспорт и композиция; `src/api.ts` — команды API;
`src/types.ts` — существующий публичный контракт; `src/components/` — карта,
энергетический инспектор, журнал; `src/mapMath.ts` — координаты/масштаб/растр;
`src/presentation.ts` — отображение публичных статусов и известных сообщений;
`src/i18n/` — словари, типы и контекст языка.
