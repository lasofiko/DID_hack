# Frontend — назначить исполнителя внутри команды

React/TypeScript dashboard DID LAB: настоящая карта, pose/yaw, траектория,
план/цель, известные энергетические оценки, батарея и исследовательский журнал.
Start/Pause/Resume/Return/Stop/Reset используют FastAPI, решения робота здесь
не вычисляются. При потере связи интерполяция прекращается; сохраняется
последняя измеренная поза. Скрытые цели и будущие события не отображаются.

Контракты: [API](../../docs/api.md). В Docker frontend собирается Node 22,
готовый dist обслуживается FastAPI на том же origin: отдельный web-сервер не нужен.
Запуск и браузерная проверка: [QUICK_START](../../docs/QUICK_START.md),
[validation](../../docs/validation.md). Командные роли: [team](../../docs/team.md).
