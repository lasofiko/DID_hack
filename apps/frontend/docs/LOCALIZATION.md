# Локализация DID LAB: русский и татарский

Русский (`ru-RU`) — по умолчанию. Татарский (`tt-RU`) — альтернативный язык
на кириллице. Переключатель в шапке меняет контекст React без перезагрузки.
Ключ `did-lab.locale` в localStorage сохраняет выбор; неизвестное значение,
недоступное хранилище или первый запуск дают русский. Обновляются также
`html.lang`, заголовок вкладки, сообщения уже выполненных команд и aria-подписи.

`src/i18n/ru.ts` задаёт стабильные ключи; `tt.ts` обязан реализовать весь набор
через `Record<keyof typeof ru, string>`. `core.ts` извлекает имена параметров
из русских строк литеральными типами TypeScript. Нельзя вызвать перевод с
неизвестным ключом, пропущенным или лишним параметром. Тесты дополнительно
проверяют совпадение ключей/параметров словарей и подстановку каждого шаблона.
`tests/i18n-types.test.ts` содержит отрицательные compile-time проверки.

Переведены группы `app`, `connection`, `state`, `mission`, `scenario`, `mode`,
`planner`, `metric`, `agent`, `action`, `reason`, `map`, `energy`, `journal`,
`event`: шапка, настройки и команды, состояния, ошибки клиента, подтверждение
сброса, карта и её доступные подписи, энергетическая шкала/инспектор,
фильтры/категории/пустые состояния журнала и режим презентации.

Числа и время симуляции форматируются `Intl.NumberFormat` выбранной локали.
Календарных дат в текущем API нет. Не изменяются числовые значения телеметрии,
идентификаторы сценариев/режимов, коды событий и команды API.
Используется системный шрифт с fallback Segoe UI / Noto Sans / sans-serif;
словарный тест проверяет наличие Ә Ө Ү Җ Ң Һ. В браузере татарские строки
отобразились, но это не проверка всех платформенных шрифтов.

Известные точные строки текущего агента имеют явные соответствия в
`presentation.ts`; произвольный текст LLM/ошибок и диагностические структуры
не переводятся догадками. Они помечены как «Оригинальное техническое сообщение».
Смысл и содержание ошибок сохраняются, включая HTTP-код.
Новые структурированные типы следует добавлять явными ключами/шаблонами.

## Проверка носителем

Особенно проверить: «бәяләмә» (estimate), «билгесезлек» (статистическая uncertainty),
«маршрутларның авырлыклары» (веса графа), «җайлашу режимы» (Adaptive),
«алгоритмик резерв» (fallback), «күзәнәк» (пространственная ячейка),
«үлчәүләр таралышы» (разброс), «медиан сигнал» и «хөкемдар» (программный судья).
Также проверить порядок слов и согласование параметризованного сообщения
о доставленных образцах; числовые шаблоны намеренно избегают русских окончаний.
