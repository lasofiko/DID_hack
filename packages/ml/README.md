# ML — Соня и Мария

Соня: будущий planner.py реализует Planner — Observation → Subgoal через LLM.
Мария: energy.py реализует EnergyModel и TurnEnergyModel — независимые оценки
расхода на метр и радиан по клеткам, неопределённость и прогноз энергии одного заданного действия.
Прогноз — расход на метр × длина либо расход на радиан × угол, без суммы.
Неизвестные будущие движения или повороты не прогнозируются.
Повороты на месте требуют измеренного суммарного угла; смешанные замеры не обучают
компоненты. Подключение и ограничения: ../../docs/energy.md.
Подписи: ../contracts/did_core/ports.py. Типы: ../contracts/did_core/types.py.
Не читать скрытые цели из environment. Подробности: ../../docs/team.md.
Planner пока не реализован. Пример энергии: experiments/energy_demo.py из корня.
