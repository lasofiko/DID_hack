# Environment — отдельный локальный mock

`did_environment/mock_judge.py` генерирует seed-сцену из публичной карты:
EASY 3 образца/1 дорогая зона; MEDIUM 5/3 без временных изменений;
HARD 7/4 со скрытым изменением расхода, опасной зоной и сбоем сигнала.
Геометрия, коэффициенты и расписание остаются приватными. Генератор независим
от clearance агента: судья использует фиксированные 0.20 м.

Зоны реально влияют на расход движения; повороты имеют отдельную малую стоимость.
Сигнал зависит от ближайшего оставшегося образца плюс шум; скрытые координаты
не передаются агенту. collect проверяет радиус и батарею, finish — базу/батарею.
Это **mock-правила**, не подтверждённые параметры официального судьи.

ROS JudgeNode — отдельный процесс, явно включаемый mock_judge:=true.
/start запускает эпоху HARD при начале миссии, поэтому ожидание пользователя
в IDLE не активирует скрытые события. Публикуются только разрешённые датчики,
счёт и уже случившиеся encounter-события без координат опасности.
Приватный журнал изменений пишется только в отдельный debug-файл судьи,
который backend не обслуживает.

Общий scene generator проверен на нескольких seed. Изолированные unit-тесты
могут читать приватные fixture-данные для проверки среды; agent и web не читают.
Запуск рядом с официальным судьёй запрещён: mock должен быть выключен.
